# Electrotecnia · Guía para aprobar (GIEyA, UPCT)

Guía de estudio de **Electrotecnia** (2.º curso, 2.º cuatrimestre del Grado en Ingeniería Electrónica Industrial y Automática, UPCT), con las ocho unidades de máquinas eléctricas explicadas desde cero, **9 figuras interactivas** y **9 problemas de examen reales resueltos** paso a paso.

🔗 **https://helionacon-ui.github.io/GIEIA-UPCT/electrotecnia/**

## Contenido

| Tema | Título |
|---|---|
| 1 | Accionamientos y requerimientos mecánicos |
| 2 | Circuitos magnéticos y transformadores |
| 3 | Conversión de energía electromecánica |
| 4 | Máquinas de corriente continua |
| 5 | Máquinas de alterna y vectores espaciales |
| 6 | Máquinas asíncronas |
| 7 | Máquinas síncronas de imanes permanentes |
| 8 | Motores de reluctancia variable |

Además: cómo es la evaluación, 46 cuestiones de teoría respondidas, los exámenes resueltos, las seis colecciones de problemas con estrategia, las prácticas de laboratorio y un formulario completo.

Datos tomados del curso 2022/23 (guía docente, apuntes, formulario y colecciones de problemas de examen de 2012 a 2022). Página creada en noviembre de 2026. Guía no oficial.
